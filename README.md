# IISER Bhopal WiFi Login

Automatic login script for the IISER Bhopal Fortigate captive portal.

## Requirements

```bash
pip install requests urllib3
```

## Usage

```bash
python wifi_login.py
```

Enter your username and password when prompted.

## Features

- Detects captive portal automatically
- Extracts Fortigate login parameters
- Logs in automatically
- Verifies internet connectivity
